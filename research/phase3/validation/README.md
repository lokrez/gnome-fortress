# Validation log guide

Accepted final results: benchmark-accepted.log, observer-refined.log,
final-regression.log, equivalence.log, historical-verification.log and
profile-after.log. All failed or superseded test/benchmark logs are retained
as diagnostic records; the defect log explains corrections before acceptance.
The headless code inventory and final observer manifest have separate scopes.
Original engine/storage and timed harnesses did not change during accepted
headless measurements. The later observer/source-verification refinements
are explicit in historical-verification.json.
